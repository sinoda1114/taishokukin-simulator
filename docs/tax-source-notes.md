# 退職金シミュレーター 出典メモ（端数・みなし・月次）

作成日: 2026-09-20  
対象: [`REQUIREMENTS.md`](./REQUIREMENTS.md) §16 相当  
決定済み（覆さない）: みなし判定は重複減算の前／同年でも DC と一般は別窓／勤続は月近似／重複側に 80万下限を掛けない

一次情報（法令・通達・国税庁タックスアンサー・総務省）だけを正とする。二次解説は手掛かりに使ったが、断定の根拠にしない。公式の本文・設例が見つからないものは「取れない」と書く。

シミュレーターの税額は、要件どおり **「退職所得の受給に関する申告書」提出済みの源泉徴収** を正とする（未提出の 20.42% は対象外）。

---

## 1. 端数の適用順

### 1.1 結論（取れた）

| 段階 | 規則 |
|---|---|
| 収入 − 退職所得控除 | この残額では切捨てない |
| × 1/2 | 残額に乗じる（切捨ての前） |
| 1,000円未満 | **×1/2 のあと** の金額（課税退職所得金額／退職所得の金額）を切捨て |
| 所得税・復興特別所得税 | 速算表 `(A×税率−控除)×102.1%`。**途中で切捨てず**、所得税と復興税の **合計** に **1円未満切捨て** |
| 住民税 | **10% を一括しない**。市町村民税 6% と道府県民税 4% を **別々に** 掛け、**それぞれ 100円未満切捨て** して足す |

### 1.2 収入−控除、×1/2、1,000円

所得税法 30条2項は、退職所得の金額を「収入金額から退職所得控除額を控除した残額の二分の一」と定める。この条文自体に千円切捨てはない。

千円切捨ての置き場所は次で一致する。

- 所得税法 201条1項1号イ（申告書提出・一般退職手当等）: 「残額の二分の一に相当する金額（当該金額に千円未満の端数があるとき、又は当該金額の全額が千円未満であるときは、その端数金額又はその全額を切り捨てた金額）」。「当該金額」は二分の一に相当する金額。
- 国税通則法 118条1項: 課税標準に千円未満の端数（または全額が千円未満）があるときは切捨て。
- タックスアンサー No.2735: 「収入金額から退職所得控除額を控除した残額に2分の1を乗じて課税退職所得金額（1,000円未満切捨て）」。具体例も「差し引いた金額を2分の1にします（2分の1にした金額に1,000円未満の端数があるときは、その端数を切り捨てます）」。
- タックスアンサー No.2732 注1: 「課税退職所得金額に1,000円未満の端数があるときは、これを切り捨てます」。
- 総務省（平成25年以後の退職所得に対する住民税）: 「収入金額から退職所得控除額を差し引いた後の金額に2分の1を乗じて得た額」に千円未満があれば切捨て。

残額を先に千円切捨てしてから ×1/2 する読みは、201条の括弧書きと No.2735 の括弧書きに合わない。市町村の計算例も、残額×1/2 で 50銭が出たあとで千円切捨てている（例: 浜松市 `(15,313,633−11,500,000)×1/2＝1,906,816.5` → `1,906,000`）。

収入が控除以下なら残額は 0 以下。課税退職所得は 0（千円切捨ての対象になる金額がない）。

### 1.3 所得税・復興特別所得税の円未満

源泉徴収では、所得税と復興特別所得税を別々に円未満切捨てしない。

- 復興財確法 31条2項: 源泉徴収に係る復興特別所得税と、その基準所得税額である所得税の確定金額の端数は、国税通則法 119条にかかわらず **合計額** で行い、合計に1円未満（または全額が1円未満）があれば切捨て。
- 国税庁「復興特別所得税（源泉徴収関係）Q&A」Q6: 「計算の途中では端数処理を行わず、最後に1円未満の端数を切り捨て」。合計税率（所得税率×102.1%）を掛けた金額に対して切捨て。
- No.2732 計算例: `(400万円×20%−427,500円)×102.1%＝380,322.5円` → `380,322円`（1円未満切捨て）。
- No.2735: 速算表適用後の税額は「1円未満切捨て」。

国税通則法 119条1項の「確定金額は100円未満切捨て」は、復興財確法 31条2項が源泉徴収について排除する。確定申告側は合計で100円切捨ての規定があるが、本シミュレーターは申告書提出済みの源泉を正とするため **合計1円切捨て** を採用する。

表示で所得税と復興税を分けるときは、所得税は速算表の `(A×税率−控除)`（円）、復興税は「合計（1円切捨て後）−所得税」とする。所得税だけ先に切捨ててから ×2.1% してはいけない。

令和9年以後の防衛特別所得税＋復興税（合計 2.1%）は、合計税率 102.1% が変わらない（国税庁 令和8年度改正の源泉関係資料）。エンジンの端数順は同じ。税率テーブルの切替は別問題。

### 1.4 住民税は 6% と 4% を別々

10% を一度掛けてから 100円切捨てる方式は、法令の税率の置き方と合わない。端数が残る金額では税額が 100円ずれる。

- 地方税法 50条の4: 道府県民税の分離課税に係る所得割の税率は **百分の四**。
- 地方税法 328条の3: 市町村民税の分離課税に係る所得割の税率は **百分の六**。
- 地方税法 20条の4の2第1項: 課税標準は千円未満切捨て（退職所得の金額）。
- 同条3項: 地方税の確定金額は100円未満切捨て。
- 総務省（平成25年以後）: 「特別徴収すべき税額（市町村民税額、道府県民税額）に、百円未満の端数がある場合は、**それぞれ** 百円単位未満の端数を切り捨てる」。
- 浜松市の設例（一次の計算手順の実例）: `1,906,000×6%＝114,360` → `114,300`、`1,906,000×4%＝76,240` → `76,200`。合計 `190,500`。10% 一括なら `190,600` になり、一致しない。

20条の4の2第8項が市町村民税と道府県民税を「一の地方税とみなす」のは、同項が指す範囲（全額が100円未満のときの全額切捨て等）に限る。端数切捨て本体を合算する趣旨ではない。総務省の「それぞれ」がこれを裏付ける。

## 2. みなし逆算（令70条2項）

### 2.1 発動条件（取れた）

前の退職手当等の収入金額が、前の退職手当等について **令70条1項2号（重複減算）を適用しないで** 計算した **所得税法 30条3項** の退職所得控除額に満たないとき。

30条3項は年数式だけである。

- 20年以下: `40万円 × 勤続年数`
- 20年超: `800万円 + 70万円 × (勤続年数 − 20)`

ここに **80万円下限（30条6項2号）・障害 +100万円（同項3号）・重複減算（同項1号）は入らない**。

確認質問 3 の「調整前」は「前の手当等自身の重複減算後と比べない」という決定で、これは維持する。法令の比較額はさらに狭く、30条3項である。勤続2年以上なら 30条3項 ≥ 80万円なので、80万下限を入れるかどうかは結果が同じ。勤続1年（30条3項 = 40万円、5.1 の下限なら 80万円）だけずれる。MVP は勤続5年以下の **税額を出さない** が、後の手当等から見た「前の退職手当等」の判定には 30条3項を使う。

東京国税局 文書回答 2024-03-22 も、比較を「令70条1項2号を適用しないで計算した退職所得控除額」とし、算式表は 30条3項と同じ（80万下限なし）。

### 2.2 逆算の数（取れた）

令70条2項各号。1に満たない端数は **切捨て**。国税庁 No.2732 の表も同じ。

| 前の収入 | 数 N（整数。端数切捨て） |
|---|---|
| 800万円以下 | 収入 ÷ 40万円 |
| 800万円超 | （収入 − 800万円）÷ 70万円 ＋ 20 |

20年超はこの2行目。800万円ちょうどは1行目で `800万 ÷ 40万 = 20`。800万円超〜870万円未満は2行目の端数切捨てで N = 20 のまま。

例: 収入 1,500万円 → `(1500−800)÷70 + 20 = 30`。収入 869万円 → `(69÷70)+20 ≒ 20.985` → **20**。

T5 / T12 の 20年以下（÷40万）はこの1行目で、本文の例と一致する。

### 2.3 収入が 80万円未満（取れた／80万は逆算の閾値ではない）

逆算の分岐は **800万円** であり、80万円ではない。80万円未満は「800万円以下」側で `収入 ÷ 40万円`（端数切捨て）。

- 収入 40万円ちょうど → N = 1
- 収入 39万円 → N = 0
- 勤続1年（30条3項 = 40万円）で収入 50万円 → 50万は 40万以上なので **みなし不発動**（5.1 の80万下限で比べると発動してしまうので、それをしない）

### 2.4 逆算年数 0（公式の期間解説は取れない）

N は 0 になり得る（収入が 40万円未満）。令70条2項は、就職の日または組合員等であった期間の初日から「N年を経過した日の前日まで」を前の勤続期間等とみなす。

**「N = 0 のときの期間」の公式設例・通達は見つからなかった。** 民法の期間計算の一般論で補完しない。

文言だけ読むと、0年を経過した日は起算日そのもの、その前日は起算日前なので、勤続期間等との交差は空（重複 0）になる。これは読みであり、公式の確認ではない。エンジン前の残件とする。

### 2.5 非連続区間への当て方（取れた）

令70条2項の対象は「前の退職手当等の支払金額の計算の基礎となつた **勤続期間等のうち**、就職の日または組合員等であった期間の **初日から** N年を経過した日の前日までの期間」。

- 起算は **実際の勤続・加入の初日**（会社は就職の日、DC は組合員等であった期間の初日）。
- 「経過した日」は暦の経過。空白（運用指図者など、勤続期間等に入らない期間）も経過に含む。加入月だけを積んで N年にする読みは、「経過した日」に合わない。
- 「のうち」なので、その暦の窓と **実際の勤続期間等（区間の集合）の交差** が、みなし後の前の勤続期間等。窓にかかった空白は交差に入らない。

東京国税局 文書回答は、同一年に前の手当等が複数あるときの起算を「それぞれの就職の日等のうち最も早い日」とする（種類をまたいで1つの前の塊にする場合）。本年分の翌年以降の窓は種類別、という決定とは別レイヤ。みなしの起算が「初日」であることの補強に使う。

月近似への落としは §3.3。

## 3. 区間の月次規則

日で数えるのが条文。月近似は決定済み。ここでは日の条文を示し、月へ落とす読みを出典付きで書く。簡易入力の「何月に置くか」は法令にない。

### 3.1 日の条文（取れた）

**勤続期間に退職の日を含む**

- 所令 69条1項1号: 「支払者の下においてその退職手当等の支払の基因となつた **退職の日まで** 引き続き勤務した期間」。
- タックスアンサー No.2735 具体例: A社 平成29年4月1日〜令和8年3月31日を勤続 9年（ちょうど。終了日を含む）。

**暦・30日＝1月・12月＝1年**

- 所得税基本通達 30-13: 勤続期間等は暦に従って計算し、1月に満たない期間は日で数え、年数・月数・日数を合計し、**日数は30日をもって1月、月数は12月をもって1年**。組合員等であった期間も同じ。

**勤続年数は1年未満切上げ、重複年数は切捨て**

- 所令 69条2項: 計算した期間に1年未満の端数を生じたときは、これを1年として勤続年数を計算する。
- 所令 70条3項: 重複している部分の期間に1年未満の端数があるときは、その端数を切り捨てる。
- No.1420 例: 勤続 10年2か月 → 11年（2か月を1年に切上げ）。
- No.2732 / No.2735: 重複期間の1年未満は切捨て。

日条文のままなら、1年と1日でも「1年未満の端数」があり勤続は切上げ（通達 30-13 で1日は1月に繰り上がらない。端数のまま切上げ）。

### 3.2 月への読み（決定済みの近似。日条文からの写像）

入力は `YYYY-MM`。日は持たない。

| 日の条文 | 月近似の読み |
|---|---|
| 退職の日まで（終了日を含む） | **終了月を含む**。開始月も1か月目 |
| 通達 30-13 の月の合計 | 月数 = `(終了年−開始年)×12 + (終了月−開始月) + 1` |
| 所令 69条2項（勤続の切上げ） | 月数を12で割った余りが **1以上** なら年は切上げ。余り 0 ならちょうど N年 |
| 所令 70条3項（重複の切捨て） | 月数を12で割った商（余り切捨て）が重複年数 |

T6「20年3か月 → 21年」: 243か月 = 20年3か月 → 余り3 → 勤続 21年。同じ 243か月の重複なら余り切捨てで 20年。

終了月を含めないと、4月1日〜翌3月31日の1年ちょうどが 11か月になり、No.2735 の 4/1〜3/31＝9年と整合しない。

月近似と日計算のずれ（公式の欠陥ではなく近似のコスト）: 開始日が月末寄りで、終了日が翌年同月のより前の日、のとき。日なら1年未満、月なら開始月〜終了月で13か月 → 勤続2年、があり得る。日を使わない決定の範囲。

複数区間は、各区間の月数を足してから年に換算する（通達 30-13 の「それぞれ合計し」の月版）。交差は月の集合演算。

### 3.3 みなし N年の月近似（取れた読み）

日: 初日から N年を経過した日の前日まで。  
例: 初日 2000-04-01、N = 12 → 2012-04-01 の前日 = 2012-03-31。含む月は 2000-04 から 2012-03。

月: **開始月を1か月目として N×12 か月**。終了月は開始月の N年後の前月。非連続なら、その月の窓と実際の加入月集合の交差。空白月は経過には含むが、交差には入らない。

### 3.4 簡易入力の開始月・終了月（取れない）

「勤続年数だけ」から区間を復元する規則は、所得税法・施行令・通達・タックスアンサーのどれにもない。製品の入力規則であり、法令の結論ではない。

終了＝退職年の何月か、開始＝終了−年数の何月か、は **未確定のまま残す**。仮置き（例: 終了 12月、開始 翌年同月の1年前）を法令として書かない。

## 4. まだ取れないもの

- **逆算 N = 0 のときの期間**の公式解説・設例。文言読みは空期間（重複 0）だが、断定しない。
- **簡易入力**の開始月・終了月。法令に無い。
- 月近似で **日を捨てたことによる1日分のずれ**を法令がどう扱うか。扱わない（日を使わない決定）。
